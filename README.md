# Hybryd marketing site

Source for www.hirehybryd.com. Plain HTML/CSS, hosted on GitHub Pages.

- Pages: index.html (/), partners.html, professionals.html, our-story.html, privacy-policy.html, terms-of-use.html
- Assets: css/site.css, js/, images/
- Push to `main` to publish. GitHub Pages rebuilds in about a minute.
- Keep URL paths unchanged. Update sitemap.xml when adding or removing pages.
- Forms and the booking calendar are GoHighLevel embeds.
